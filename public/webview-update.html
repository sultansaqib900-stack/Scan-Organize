This tablet needs newer system software.

Scan & Organize needs Fire OS 7 or newer and a system WebView based on Chromium 111 or newer. The Fire OS version alone does not guarantee a compatible WebView.

On a Fire tablet, check Settings → Device Options → System Updates for official Amazon updates, then reopen the app. Updating system software may require an internet connection; using this app on a compatible tablet does not.

Amazon System WebView is supplied by Amazon. You do not need Google Play, Google Chrome, or Google's Android System WebView. Installing those is not a supported fix.

If Amazon no longer provides a compatible update for this model, this app build cannot run on it. Your saved documents have not been changed. Do not uninstall the app or clear its data to resolve this message.
